# Lockon · atualizações

Página de download do **Lockon**, painel de tracking para o Premiere Pro.

**[Baixar a versão mais nova](https://github.com/Edueditor/lockon-updates/releases/latest/download/Lockon_completo.zip)** · o zip traz o plugin (`Lockon.zxp`), o guia em PDF, o vídeo de apresentação e o link do ZXP Installer.

Para atualizar: feche o Premiere e arraste o `Lockon.zxp` novo no ZXP Installer. O motor de tracking não precisa ser instalado de novo.

O painel lê o arquivo `latest.json` deste repositório uma vez por dia para avisar quando há versão nova.
